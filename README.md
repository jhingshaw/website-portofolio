## 📌 About The Project

**JhingShaw.lab** is not just a standard resume—it is a comprehensive digital identity designed to showcase my journey as a Web Developer and future AI Engineer. Built with a modern, cyberpunk-inspired UI, this project serves as the central hub for all my code, experiments, and automation tools.

This project was engineered with a **Zero-Build Architecture**, meaning it is incredibly lightweight, runs perfectly without complex bundlers, and is fully maintainable via mobile development environments (like SPCK Editor).

## ✨ Key Features

- **🤖 Strict-Context AI Assistant (Client-Side Logic):** 
  Features a custom-built, rule-based virtual assistant that uses keyword matching and intent recognition to answer visitor queries strictly within the context of the website. It includes an anti-bypass mechanism to reject out-of-scope questions automatically.
- **🚀 Launch Hub Ecosystem:** 
  A dedicated directory system equipped with dynamic filtering and search capabilities to categorize live projects, tools, AI experiments, and learning notes instantly without page reloads.
- **🎨 Futuristic & Responsive UI/UX:** 
  Utilizes advanced CSS techniques including radial gradients, glassmorphism (backdrop-filters), CSS masks, and custom animations to create a premium "hacker/prodigy" aesthetic.
- **⚡ High Performance:** 
  Purely built with Vanilla technologies, ensuring instant load times and zero dependency overhead.

## 🛠️ Technology Stack

- **Frontend Structure:** HTML5 (Semantic & Accessible)
- **Styling:** CSS3 (Custom Properties, Flexbox, CSS Grid Layouts, Keyframe Animations)
- **Logic & Interactions:** Vanilla JavaScript (ES6+)
- **Deployment:** Vercel

## 🧠 Architecture Highlights

To maintain high performance and avoid server costs, this project relies heavily on **Advanced Client-Side Logic**. 
- The **Customer Service AI** does not rely on external API calls (which prevents API key leakage and reduces latency). Instead, it uses a lightweight JS array-matching algorithm to parse natural language inputs.
- The **Launch Hub** uses DOM manipulation to filter and render project cards instantly without making redundant database queries.
